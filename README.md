# Peugeot 206 Mantenimiento 🚗🔧

Aplicación web progresiva (PWA) para el registro, seguimiento y control de mantenimientos preventivos y correctivos del Peugeot 206.

## 🚀 Características
- **Control de mantenimientos:** Registro de servicios, cambios de aceite, filtros, distribución, frenos y más.
- **PWA (Progressive Web App):** Instalable en dispositivos móviles (Android / iOS) y PC con soporte offline mediante Service Worker.
- **Historial y alertas:** Seguimiento por kilometraje y fechas para no olvidar ningún servicio importante.
- **Interfaz moderna y oscura:** Diseñada para uso ágil y con mínimo consumo de recursos.

## 🛠️ Tecnologías
- HTML5 / CSS3 / JavaScript (Vanilla)
- Service Worker & Web App Manifest (PWA)
- LocalStorage para persistencia local de datos

## 💻 Instalación y Uso
1. Clona este repositorio:
   ```bash
   git clone https://github.com/elvio3780-debug/mantenimiento-p206.git
   ```
2. Abre `index.html` en tu navegador o sírvelo con un servidor local (por ejemplo con Live Server en VS Code o Python `python -m http.server`).
